## **Godot Gamepad Led Manager**

***A simple gamepad led manager addon for Godot Engine 4.6+.***
*Tested on Godot Engine 4.6 Stable on Linux and Windows (this should work on macOS)*

## Features
-Change and get the gamepads led color and intensity, including tweens.

-Apply effects to the gamepads led color (like pulse or rainbow) with the ability to pass custom parameters for a better customization.

-Turn ON / OFF the gamepads leds in an easy way.
